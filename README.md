# YouTube Local Translator

YouTubeの音声をChromeのオンデバイス音声認識で文字起こしし、Chrome Translator APIでローカル翻訳するManifest V3拡張機能です。

## このMVPの範囲

- 対象はYouTubeの通常動画・ライブ・アーカイブ
- 日本語・英語・インドネシア語の自動判定、または単一言語の指定
- 言語指定時は指定言語の認識1本で処理し、自動判定用の候補比較・待ち合わせを通さず結果を表示・翻訳へ渡す
- 自動判定では、チャンネルから推定した言語または手動指定した優先言語を候補選択に反映
- Popupでホロライブ辞書をONにした場合、公式メンバー名、呼び方・呼ばれ方、固有語を弱い音声認識ヒントに追加
- 大量の連続反復や文字を含まない候補を除外し、低信頼度の候補はセッションの言語学習に使用しない
- 認識候補を発話ごとに選び、混在する言語部分を指定した翻訳先へ変換
- 話し続ける場合も認識を止めず、安定した途中結果を文末・文字数・経過時間を目安に区切って先に表示・翻訳する
- プレイヤーと動画タイトルの間に最新の原文・翻訳を表示
- 原文の更新中も訳文は消さず、次の翻訳が完成した時点で更新する
- PopupをONにしたタブだけ翻訳UIを表示し、パネル右上の×で停止してOFFに戻す
- Chrome Built-in AIのSpeechRecognition / Translator APIを優先
- 文字起こし・翻訳結果を保存せず、外部サーバーへ送信しない
- YouTubeのSPA遷移でセッションとUIを再接続
- ホロライブ辞書・原文表示・翻訳表示・フォントサイズ・ON/OFFをPopupで設定

字幕履歴、日本語・英語・インドネシア語以外の言語、クラウドAPI、Gemini Nano、エクスポートはこのMVPには含めていません。

## 導入

1. `npm run build` を実行する。
2. Chromeで `chrome://extensions` を開く。
3. デベロッパーモードを有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」で `dist` フォルダーを選ぶ。
5. YouTubeの動画ページを開き、拡張機能Popupの `ON` を押す。
6. ChromeがAPIまたはモデルを利用できない場合は、Popupまたはパネルのエラー案内に従う。

`tabCapture` はユーザー操作後に開始する必要があります。音声取得開始時は、捕捉した音声をAudioContextから出力先へ戻して、YouTubeの音が消えないようにしています。

## Chrome側の前提

Chromeのバージョン、端末性能、Built-in AIのモデル状態によって利用可否が変わります。自動判定ではSpeechRecognitionの日本語・英語・インドネシア語ローカル言語パックを使用し、複数の認識候補から発話ごとの言語を選びます。必要な音声認識・言語判定・翻訳モデルを利用できない場合、拡張機能はクラウドへフォールバックせず、明示的にエラーを表示します。

「自動判定の優先言語」を「チャンネルから推定」にすると、ホロライブJPのチャンネルでは日本語、ホロライブEN・IDでは英語を候補選択で少し優先します。短く曖昧な発話では優先度をやや強めます。推定が合わないチャンネルでは、日本語・英語・インドネシア語を直接指定するか「優先なし」を選べます。

ホロライブ辞書は初期状態ではOFFです。ONにすると、自動判定では日本語・英語・インドネシア語の各認識器へ、その言語向けの辞書ヒントだけを渡します。認識の信頼度を中心に候補を比較し、文字種やテキストの言語判定は補助として扱います。同じ単語・短い句が6回以上連続し、候補の大部分または長い区間を占める場合は、途中表示・翻訳・学習の対象から除外します。短い自然な繰り返しは残しますが、長い掛け声など実際の反復も除外される場合があります。

辞書には公式名に加えて、ホロライブ非公式wikiの呼称一覧を基にした「みこち」「そら先輩」「ねねち」などの頻出呼称と、「あえんびえん」「ギョリノフ」などの固有語を収録しています。「私」「みんな」のような一般語や一時的な呼称は、誤認識を増やさないため収録していません。Chromeが文脈ヒントに対応していない場合は、ヒントなしで動作します。辞書ON時は、短い発話が登録語と完全一致した場合に固有名の公式表記や語録の意味を優先して翻訳します。呼称一覧の参照元: https://seesaawiki.jp/hololivetv/d/%A5%DB%A5%ED%A5%E9%A5%A4%A5%D6%A1%DA%B8%C6%BE%CE%B0%EC%CD%F7%A1%DB

Translator APIのモデル作成にはユーザー操作が必要になる場合があります。その場合はPopupの操作から準備をやり直してください。

文字数・時間による `stop()` と再開は行わず、音声入力を続けます。自動判定・言語固定のどちらでも、通常の途中結果は先頭から全文を保って表示し、Chrome自身が確定してから翻訳します。時間だけを理由に前半を暫定確定しないため、認識途中で前半が消えたり、文脈の足りない断片だけが翻訳されたりすることを防ぎます。

Chromeが長時間確定せず、未確定文が日本語で約180文字、英語・インドネシア語で約480文字を超えた場合だけ、700ミリ秒以上安定した文末や文節を探して先に分割します。適切な境界がない場合は無理に単語位置で切らず、Chromeの確定結果を待ちます。自動言語判定には候補比較時間もあるため、表示や翻訳までの時間は保証されません。

日本語の認識では、日本語文字同士や日本語と数字の間に挿入された空白を揃えてから区切りを判断します。途中結果と確定結果の空白の違いによる再送や待ち直しを防ぎます。英単語間や数字同士の空白は残します。

自動判定の途中表示では、短い別言語候補だけで表示を切り替えません。現在の候補より強い認識が約600ミリ秒続いたときに切り替え、更新されない候補は約1.6秒で比較対象から外します。間が空いた後も短い候補の割り込みは防ぎますが、古い候補の信頼度で次の言語を妨げないようにしています。表示中とは別の言語の先出し区間も、一時的に割り込まないよう抑制します。並列認識で遅れて届いた別言語の確定結果も、直前の表示候補が新しい間は上書きに使いません。その別言語の途中候補が切り替え条件を満たした場合、または直前候補が古くなった場合は、実際の言語交代として確定結果を採用します。

先出しした区間はChrome自身の確定結果とは区別し、言語学習には使いません。Chromeの確定結果が届いたら未処理の続きだけを送ります。認識が前の部分を書き換えた場合は境界位置を合わせ直し、対応が曖昧な場合は頭切れを避けるため訂正文を再表示します。先出しした翻訳を過去にさかのぼってすべて訂正する機能はありません。

原文と訳文は独立して更新します。次の原文や途中結果が届いても、表示中の訳文は次の翻訳が完成するまで残します。原文が先に進んでから完成した翻訳も表示しますが、すでに表示した翻訳より古い結果で巻き戻しません。言語設定の変更やパネルの終了時は表示をリセットします。

## 開発用チェック

依存パッケージはありません。

```powershell
npm test
npm run check
```

`npm run check` はManifestの参照先と全JavaScriptの構文を検査します。実際のChromeでの音声・モデル・YouTube DOMの動作は、Chromeの環境とユーザー操作を必要とするため、別途確認してください。

## Privacy

Audio is processed locally on your device.

No audio, transcript, or translation is sent to this extension's server. この拡張機能にはサーバー接続処理を含めていません。
